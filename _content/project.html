Como você pode ajudar

Reportar issues

Se você encontrar bugs, erros ou inconsistências no código ou documentação do projeto Go, por favor nos informe abrindo um ticket em nosso rastreador de issues. (É claro, você deve verificar se não é uma issue existente antes de criar uma nova.)

Nos orgulhamos de ser meticulosos; nenhuma issue é pequena demais.

Issues relacionadas à segurança devem ser reportadas para security@golang.org.
Veja a política de segurança para mais detalhes.

Issues relacionadas à comunidade devem ser reportadas para conduct@golang.org. Veja o Código de Conduta para mais detalhes.

Contribuir com código & documentação

Go é um projeto open source e damos boas-vindas a contribuições da comunidade.

Para começar, leia estas diretrizes de contribuição para informações sobre design, testes e nosso processo de revisão de código.

Confira o rastreador para issues abertas que lhe interessem. Aquelas marcadas como help wanted estão particularmente necessitadas de ajuda externa.
