Este tópico descreve como instalar várias versões do Go na mesma máquina, bem como como desinstalar o Go.

Para outros conteúdos sobre instalação, você pode se interessar por:

  • Download e instalação -- A maneira mais simples de instalar e executar.
  • Instalando Go do código-fonte -- Como fazer checkout dos códigos-fonte, compilá-los em sua própria máquina e executá-los.

Instalando várias versões do Go

Você pode instalar várias versões do Go na mesma máquina. Por exemplo, você pode querer testar seu código em várias versões do Go. Para uma lista de versões que você pode instalar dessa forma, veja a página de download.

Nota: Para instalar usando o método descrito aqui, você precisará ter o git instalado.

Para instalar versões adicionais do Go, execute o comando go install, especificando o local de download da versão que você deseja instalar. O exemplo a seguir ilustra com a versão 1.10.7: 

$ go install golang.org/dl/go1.10.7@latest
$ go1.10.7 download

Para executar comandos go com a versão recém-baixada, adicione o número da versão ao comando go, da seguinte forma: 

$ go1.10.7 version
go version go1.10.7 linux/amd64

Quando você tiver várias versões instaladas, poderá descobrir onde cada uma está instalada, observando o valor GOROOT da versão. Por exemplo, execute um comando como o seguinte: 

$ go1.10.7 env GOROOT

Para desinstalar uma versão baixada, basta remover o diretório especificado por sua variável de ambiente GOROOT e o binário goX.Y.Z.

Desinstalando o Go

Você pode remover o Go do seu sistema usando as etapas descritas neste tópico.

Removendo configuração e dados do usuário

Go armazena a configuração do usuário no diretório go dentro do diretório de configuração do usuário, conforme retornado por os.UserConfigDir. Isso também pode ser encontrado como o diretório que contém o arquivo de configuração retornado por go env GOENV.

Go armazena artefatos de build intermediários no diretório retornado por go env GOCACHE. Eles podem ser removidos com go clean -cache.

Go armazena dependências baixadas no diretório retornado por go env GOMODCACHE. Elas podem ser removidas com go clean -modcache.

Linux / macOS / FreeBSD

  1. Exclua o diretório go.

    Isso geralmente é /usr/local/go.

  2. Remova o diretório bin do Go da sua variável de ambiente PATH.

    No Linux e FreeBSD, edite /etc/profile ou $HOME/.profile. Se você instalou o Go com o pacote macOS, remova o arquivo /etc/paths.d/go.

Windows

A maneira mais simples de remover o Go é via Adicionar/Remover Programas no painel de controle do Windows:

  1. No Painel de Controle, clique duas vezes em Add/Remove Programs.
  2. Em Add/Remove Programs, selecione Go Programming Language, clique em Uninstall e siga as instruções.

Para remover o Go com ferramentas, você também pode usar a linha de comando:

  • Desinstale usando a linha de comando executando o seguinte comando: 
    msiexec /x go{{version}}.windows-{{cpu-arch}}.msi /q

    Nota: Usar este processo de desinstalação para Windows removerá automaticamente as variáveis de ambiente do Windows criadas pela instalação original.
