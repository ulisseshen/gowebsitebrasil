Na seção anterior, você criou um module greetings. Nesta seção, você escreverá código para fazer chamadas à função Hello no module que você acabou de escrever. Você escreverá código que pode executar como uma aplicação, e que chama código no module greetings.

Nota: Este tópico faz parte de um tutorial em múltiplas partes que começa com Create a Go module.
  1. Crie um diretório hello para o código fonte do seu module Go. Este é onde você escreverá seu caller.

    Depois de criar este diretório, você deve ter tanto um diretório hello quanto um greetings no mesmo nível na hierarquia, assim: 

    <home>/
 |-- greetings/
 |-- hello/

    Por exemplo, se seu prompt de comando está no diretório greetings, você poderia usar os seguintes comandos: 

    cd ..
mkdir hello
cd hello
  2. Habilite o rastreamento de dependências para o código que você está prestes a escrever.

    Para habilitar o rastreamento de dependências para seu código, execute o comando go mod init, informando o nome do module em que seu código estará.

    Para os propósitos deste tutorial, use example.com/hello para o module path. 

    $ go mod init example.com/hello
go: creating new go.mod: module example.com/hello
  3. No seu editor de texto, no diretório hello, crie um arquivo no qual escrever seu código e chame-o de hello.go.
  4. Escreva código para chamar a função Hello, depois imprima o valor de retorno da função.

    Para fazer isso, cole o seguinte código no hello.go. 

    package main

import (
    "fmt"

    "example.com/greetings"
)

func main() {
    // Get a greeting message and print it.
    message := greetings.Hello("Gladys")
    fmt.Println(message)
}

    Neste código, você:

    • Declara um package main. Em Go, código executado como uma aplicação deve estar em um package main.
    • Importa dois packages: example.com/greetings e o package fmt. Isso dá ao seu código acesso a funções nesses packages. Importar example.com/greetings (o package contido no module que você criou anteriormente) dá a você acesso à função Hello. Você também importa fmt, com funções para manipular texto de entrada e saída (como imprimir texto no console).
    • Obtém uma saudação chamando a função Hello do package greetings.
  5. Edite o module example.com/hello para usar seu module example.com/greetings local.

    Para uso em produção, você publicaria o module example.com/greetings do seu repositório (com um module path que refletisse sua localização publicada), onde as ferramentas Go poderiam encontrá-lo para baixá-lo. Por enquanto, porque você ainda não publicou o module, você precisa adaptar o module example.com/hello para que ele possa encontrar o código example.com/greetings no seu sistema de arquivos local.

    Para fazer isso, use o comando go mod edit para editar o module example.com/hello e redirecionar as ferramentas Go do seu module path (onde o module não está) para o diretório local (onde ele está).

    1. No prompt de comando no diretório hello, execute o seguinte comando: 
      $ go mod edit -replace example.com/greetings=../greetings

      O comando especifica que example.com/greetings deve ser substituído por ../greetings para o propósito de localizar a dependência. Depois de executar o comando, o arquivo go.mod no diretório hello deve incluir uma diretiva replace: 

      module example.com/hello

go 1.16

replace example.com/greetings => ../greetings
    2. No prompt de comando no diretório hello, execute o comando go mod tidy para sincronizar as dependências do module example.com/hello, adicionando aquelas requeridas pelo código, mas ainda não rastreadas no module. 
      $ go mod tidy
go: found example.com/greetings in example.com/greetings v0.0.0-00010101000000-000000000000

      Depois que o comando for concluído, o arquivo go.mod do module example.com/hello deve ficar assim: 

      module example.com/hello

go 1.16

replace example.com/greetings => ../greetings

require example.com/greetings v0.0.0-00010101000000-000000000000

      O comando encontrou o código local no diretório greetings, depois adicionou uma diretiva require para especificar que example.com/hello requer example.com/greetings. Você criou esta dependência quando importou o package greetings no hello.go.

      O número que segue o module path é um número de pseudo-versão -- um número gerado usado no lugar de um número de versão semântico (que o module ainda não tem).

      Para referenciar um module publicado, um arquivo go.mod normalmente omitiria a diretiva replace e usaria uma diretiva require com um número de versão com tag no final. 

      require example.com/greetings v1.1.0

      Para mais sobre números de versão, veja Module version numbering.

  6. No prompt de comando no diretório hello, execute seu código para confirmar que funciona. 
    $ go run .
Hi, Gladys. Welcome!

Parabéns! Você escreveu dois modules funcionais.
