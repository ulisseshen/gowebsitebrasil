Neste tutorial, você terá uma breve introdução à programação em Go. Ao longo do caminho, você irá:

  • Instalar Go (se você ainda não instalou).
  • Escrever um código simples "Hello, world".
  • Usar o comando go para executar seu código.
  • Usar a ferramenta de descoberta de packages do Go para encontrar packages que você pode usar no seu próprio código.
  • Chamar funções de um module externo.
Nota: Para outros tutoriais, veja Tutorials.

Pré-requisitos

  • Alguma experiência em programação. O código aqui é bastante simples, mas ajuda saber algo sobre funções.
  • Uma ferramenta para editar seu código. Qualquer editor de texto que você tenha funcionará bem. A maioria dos editores de texto tem bom suporte para Go. Os mais populares são VSCode (gratuito), GoLand (pago) e Vim (gratuito).
  • Um terminal de comando. Go funciona bem usando qualquer terminal no Linux e Mac, e no PowerShell ou cmd no Windows.

Instalar Go

Basta usar os passos de Download and install.

Escrever algum código

Comece com Hello, World.

  1. Abra um prompt de comando e navegue até seu diretório home.

    No Linux ou Mac: 

    cd

    No Windows: 

    cd %HOMEPATH%
  2. Crie um diretório hello para seu primeiro código fonte Go.

    Por exemplo, use os seguintes comandos: 

    mkdir hello
cd hello
  3. Habilite o rastreamento de dependências para seu código.

    Quando seu código importa packages contidos em outros modules, você gerencia essas dependências através do próprio module do seu código. Esse module é definido por um arquivo go.mod que rastreia os modules que fornecem esses packages. Esse arquivo go.mod permanece com seu código, incluindo no seu repositório de código fonte.

    Para habilitar o rastreamento de dependências para seu código criando um arquivo go.mod, execute o comando go mod init, informando o nome do module em que seu código estará. O nome é o module path do module.

    No desenvolvimento real, o module path normalmente será a localização do repositório onde seu código fonte será mantido. Por exemplo, o module path pode ser github.com/mymodule. Se você planeja publicar seu module para outros usarem, o module path deve ser uma localização de onde as ferramentas Go podem baixar seu module. Para mais sobre nomear um module com um module path, veja Managing dependencies.

    Para os propósitos deste tutorial, apenas use example/hello. 

    $ go mod init example/hello
go: creating new go.mod: module example/hello

  4. No seu editor de texto, crie um arquivo hello.go no qual você escreverá seu código.

  5. Cole o seguinte código no seu arquivo hello.go e salve o arquivo.

    package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

    Este é o seu código Go. Neste código, você:

    • Declara um package main (um package é uma forma de agrupar funções, e é composto por todos os arquivos no mesmo diretório).
    • Importa o popular package fmt, que contém funções para formatar texto, incluindo imprimir no console. Este package é um dos packages da biblioteca padrão que você obteve quando instalou Go.
    • Implementa uma função main para imprimir uma mensagem no console. Uma função main é executada por padrão quando você executa o package main.

  6. Execute seu código para ver a saudação.

    $ go run .
Hello, World!

    O comando go run é um dos muitos comandos go que você usará para fazer as coisas com Go. Use o seguinte comando para obter uma lista dos outros: 

    $ go help

Chamar código em um package externo

Quando você precisa que seu código faça algo que pode ter sido implementado por outra pessoa, você pode procurar por um package que tenha funções que você pode usar no seu código.

  1. Torne sua mensagem impressa um pouco mais interessante com uma função de um module externo.
    1. Visite pkg.go.dev e procure por um package "quote".
    2. Nos resultados de busca, localize e clique na v1 do package rsc.io/quote (ele deve estar listado com as "Other major versions" de rsc.io/quote/v4).
    3. Na seção Documentation, em Index, observe a lista de funções que você pode chamar do seu código. Você usará a função Go.
    4. No topo desta página, observe que o package quote está incluído no module rsc.io/quote.

    Você pode usar o site pkg.go.dev para encontrar modules publicados cujos packages têm funções que você pode usar no seu próprio código. Packages são publicados em modules -- como rsc.io/quote -- onde outros podem usá-los. Modules são aprimorados com novas versões ao longo do tempo, e você pode atualizar seu código para usar as versões aprimoradas.

  2. No seu código Go, importe o package rsc.io/quote e adicione uma chamada à sua função Go.

    Depois de adicionar as linhas destacadas, seu código deve incluir o seguinte: 

    package main

import "fmt"

import "rsc.io/quote"

func main() {
    fmt.Println(quote.Go())
}
  3. Adicione novos requisitos e somas de module.

    Go adicionará o module quote como um requisito, bem como um arquivo go.sum para uso na autenticação do module. Para mais, veja Authenticating modules na Referência de Modules Go. 

    $ go mod tidy
go: finding module for package rsc.io/quote
go: found rsc.io/quote in rsc.io/quote v1.5.2
  4. Execute seu código para ver a mensagem gerada pela função que você está chamando. 
    $ go run .
Don't communicate by sharing memory, share memory by communicating.

    Observe que seu código chama a função Go, imprimindo uma mensagem inteligente sobre comunicação.

    Quando você executou go mod tidy, ele localizou e baixou o module rsc.io/quote que contém o package que você importou. Por padrão, ele baixou a versão mais recente -- v1.5.2.
