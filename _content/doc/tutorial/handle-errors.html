Tratar erros é uma característica essencial de código sólido. Nesta seção, você adicionará um pouco de código para retornar um erro do módulo greetings, então tratará no chamador.

Nota: Este tópico é parte de um tutorial em várias partes que começa com Criar um módulo Go.
  1. Em greetings/greetings.go, adicione o código destacado abaixo.

    Não faz sentido enviar uma saudação de volta se você não sabe para quem cumprimentar. Retorne um erro para o chamador se o nome estiver vazio. Copie o seguinte código em greetings.go e salve o arquivo. 

    package greetings

import (
    "errors"
    "fmt"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return "", errors.New("empty name")
    }

    // If a name was received, return a value that embeds the name
    // in a greeting message.
    message := fmt.Sprintf("Hi, %v. Welcome!", name)
    return message, nil
}

    Neste código, você:

    • Altera a função para que ela retorne dois valores: uma string e um error. Seu chamador verificará o segundo valor para ver se ocorreu um erro. (Qualquer função Go pode retornar múltiplos valores. Para mais informações, veja Effective Go.)
    • Importa o pacote errors da biblioteca padrão Go para que você possa usar sua função errors.New.
    • Adiciona uma instrução if para verificar uma requisição inválida (uma string vazia onde o nome deveria estar) e retorna um erro se a requisição for inválida. A função errors.New retorna um error com sua mensagem dentro.
    • Adiciona nil (significando nenhum erro) como um segundo valor no retorno bem-sucedido. Dessa forma, o chamador pode ver que a função foi bem-sucedida.
  2. No seu arquivo hello/hello.go, trate o erro agora retornado pela função Hello, junto com o valor não-erro.

    Cole o seguinte código em hello.go. 

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // Request a greeting message.
    message, err := greetings.Hello("")
    // If an error was returned, print it to the console and
    // exit the program.
    if err != nil {
        log.Fatal(err)
    }

    // If no error was returned, print the returned message
    // to the console.
    fmt.Println(message)
}

    Neste código, você:

    • Configura o log package para imprimir o nome do comando ("greetings: ") no início de suas mensagens de log, sem um timestamp ou informação de arquivo fonte.
    • Atribui ambos os valores de retorno de Hello, incluindo o error, a variáveis.
    • Altera o argumento de Hello do nome de Gladys para uma string vazia, para que você possa testar seu código de tratamento de erro.
    • Procura por um valor error não-nil. Não faz sentido continuar neste caso.
    • Usa as funções no log package da biblioteca padrão para exibir informações de erro. Se você obtiver um erro, você usa a função Fatal do pacote log para imprimir o erro e parar o programa.
  3. Na linha de comando no diretório hello, execute hello.go para confirmar que o código funciona.

    Agora que você está passando um nome vazio, você receberá um erro. 

    $ go run .
greetings: empty name
exit status 1

Esse é o tratamento de erro comum em Go: Retorne um erro como um valor para que o chamador possa verificá-lo.
