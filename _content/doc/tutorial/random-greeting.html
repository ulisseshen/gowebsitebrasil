Nesta seção, você mudará seu código para que, em vez de retornar uma única saudação toda vez, ele retorne uma das várias mensagens de saudação predefinidas.

Nota: Este tópico é parte de um tutorial em várias partes que começa com Criar um módulo Go.

Para fazer isso, você usará um slice Go. Um slice é como um array, exceto que seu tamanho muda dinamicamente conforme você adiciona e remove itens. O slice é um dos tipos mais úteis do Go.

Você adicionará um pequeno slice para conter três mensagens de saudação, então terá seu código retornando uma das mensagens aleatoriamente. Para mais sobre slices, veja Go slices no blog do Go.

  1. Em greetings/greetings.go, mude seu código para que fique assim. 
    package greetings

import (
    "errors"
    "fmt"
    "math/rand"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return name, errors.New("empty name")
    }
    // Create a message using a random format.
    message := fmt.Sprintf(randomFormat(), name)
    return message, nil
}

// randomFormat returns one of a set of greeting messages. The returned
// message is selected at random.
func randomFormat() string {
    // A slice of message formats.
    formats := []string{
        "Hi, %v. Welcome!",
        "Great to see you, %v!",
        "Hail, %v! Well met!",
    }

    // Return a randomly selected message format by specifying
    // a random index for the slice of formats.
    return formats[rand.Intn(len(formats))]
}

    Neste código, você:

    • Adiciona uma função randomFormat que retorna um formato selecionado aleatoriamente para uma mensagem de saudação. Note que randomFormat começa com uma letra minúscula, tornando-a acessível apenas ao código em seu próprio pacote (em outras palavras, ela não é exportada).
    • Em randomFormat, declara um slice formats com três formatos de mensagem. Ao declarar um slice, você omite seu tamanho nos colchetes, assim: []string. Isso diz ao Go que o tamanho do array subjacente ao slice pode ser mudado dinamicamente.
    • Usa o math/rand package para gerar um número aleatório para selecionar um item do slice.
    • Em Hello, chama a função randomFormat para obter um formato para a mensagem que você retornará, então usa o formato e o valor name juntos para criar a mensagem.
    • Retorna a mensagem (ou um erro) como você fez antes.
  2. Em hello/hello.go, mude seu código para que fique assim.

    Você está apenas adicionando o nome de Gladys (ou um nome diferente, se preferir) como um argumento para a chamada da função Hello em hello.go.

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // Request a greeting message.
    message, err := greetings.Hello("Gladys")
    // If an error was returned, print it to the console and
    // exit the program.
    if err != nil {
        log.Fatal(err)
    }

    // If no error was returned, print the returned message
    // to the console.
    fmt.Println(message)
}
  3. Na linha de comando, no diretório hello, execute hello.go para confirmar que o código funciona. Execute várias vezes, notando que a saudação muda.

$ go run .

$ go run .
