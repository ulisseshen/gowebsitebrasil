Neste último tópico, você aprenderá alguns novos comandos go. Embora o comando go run seja um atalho útil para compilar e executar um programa quando você está fazendo mudanças frequentes, ele não gera um executável binário.

Este tópico introduz dois comandos adicionais para construir código:

  • O comando go build compila os pacotes, junto com suas dependências, mas não instala os resultados.
  • O comando go install compila e instala os pacotes.
Nota: Este tópico é parte de um tutorial em várias partes que começa com Criar um módulo Go.
  1. Na linha de comando no diretório hello, execute o comando go build para compilar o código em um executável. 
    $ go build
  2. Na linha de comando no diretório hello, execute o novo executável hello para confirmar que o código funciona.

    Note que seu resultado pode diferir dependendo se você mudou seu código greetings.go depois de testá-lo.

    • No Linux ou Mac: 
      $ ./hello
map[Darrin:Great to see you, Darrin! Gladys:Hail, Gladys! Well met! Samantha:Hail, Samantha! Well met!]
    • No Windows: 
      $ hello.exe
map[Darrin:Great to see you, Darrin! Gladys:Hail, Gladys! Well met! Samantha:Hail, Samantha! Well met!]

    Você compilou o aplicativo em um executável para poder executá-lo. Mas para executá-lo atualmente, seu prompt precisa estar no diretório do executável, ou especificar o caminho do executável.

    A seguir, você instalará o executável para poder executá-lo sem especificar seu caminho.

  3. Descubra o caminho de instalação do Go, onde o comando go instalará o pacote atual.

    Você pode descobrir o caminho de instalação executando o comando go list, como no seguinte exemplo: 

    $ go list -f '{{.Target}}'

    Por exemplo, a saída do comando pode dizer /home/gopher/bin/hello, significando que binários são instalados em /home/gopher/bin. Você precisará deste diretório de instalação no próximo passo.

  4. Adicione o diretório de instalação do Go ao caminho shell do seu sistema.

    Dessa forma, você será capaz de executar o executável do seu programa sem especificar onde o executável está.

    • No Linux ou Mac, execute o seguinte comando: 
      $ export PATH=$PATH:/path/to/your/install/directory
    • No Windows, execute o seguinte comando: 
      $ set PATH=%PATH%;C:\path\to\your\install\directory

    Como alternativa, se você já tem um diretório como $HOME/bin no seu caminho shell e gostaria de instalar seus programas Go lá, você pode mudar o destino de instalação definindo a variável GOBIN usando o comando go env: 

    $ go env -w GOBIN=/path/to/your/bin

    ou 

    $ go env -w GOBIN=C:\path\to\your\bin
  5. Uma vez que você atualizou o caminho shell, execute o comando go install para compilar e instalar o pacote. 
    $ go install
  6. Execute seu aplicativo simplesmente digitando seu nome. Para tornar isso interessante, abra um novo prompt de comando e execute o nome executável hello em algum outro diretório. 
    $ hello
map[Darrin:Hail, Darrin! Well met! Gladys:Great to see you, Gladys! Samantha:Hail, Samantha! Well met!]

Isso encerra este tutorial do Go!
