Pré-requisitos

  • Alguma experiência em programação. O código aqui é bastante simples, mas ajuda saber algo sobre funções, loops e arrays.
  • Uma ferramenta para editar seu código. Qualquer editor de texto que você tenha funcionará bem. A maioria dos editores de texto tem bom suporte para Go. Os mais populares são VSCode (gratuito), GoLand (pago) e Vim (gratuito).
  • Um terminal de comando. Go funciona bem usando qualquer terminal no Linux e Mac, e no PowerShell ou cmd no Windows.

Inicie um module que outros podem usar

Comece criando um module Go. Em um module, você coleta um ou mais packages relacionados para um conjunto discreto e útil de funções. Por exemplo, você pode criar um module com packages que tenham funções para fazer análise financeira para que outros que escrevem aplicações financeiras possam usar seu trabalho. Para mais sobre desenvolvimento de modules, veja Developing and publishing modules.

Código Go é agrupado em packages, e packages são agrupados em modules. Seu module especifica dependências necessárias para executar seu código, incluindo a versão do Go e o conjunto de outros modules que ele requer.

À medida que você adiciona ou melhora funcionalidades no seu module, você publica novas versões do module. Desenvolvedores que escrevem código que chama funções no seu module podem importar os packages atualizados do module e testar com a nova versão antes de colocá-la em uso de produção.

  1. Abra um prompt de comando e execute cd para seu diretório home.

    No Linux ou Mac: 

    cd

    No Windows: 

    cd %HOMEPATH%
  2. Crie um diretório greetings para o código fonte do seu module Go.

    Por exemplo, do seu diretório home use os seguintes comandos: 

    mkdir greetings
cd greetings
  3. Inicie seu module usando o comando go mod init.

    Execute o comando go mod init, informando o module path -- aqui, use example.com/greetings. Se você publicar um module, este deve ser um caminho do qual seu module pode ser baixado pelas ferramentas Go. Esse seria o repositório do seu código.

    Para mais sobre nomear seu module com um module path, veja Managing dependencies. 

    $ go mod init example.com/greetings
go: creating new go.mod: module example.com/greetings

    O comando go mod init cria um arquivo go.mod para rastrear as dependências do seu código. Até agora, o arquivo inclui apenas o nome do seu module e a versão Go que seu código suporta. Mas à medida que você adiciona dependências, o arquivo go.mod listará as versões das quais seu código depende. Isso mantém as builds reproduzíveis e dá a você controle direto sobre quais versões de module usar.

  4. No seu editor de texto, crie um arquivo no qual escrever seu código e chame-o de greetings.go.
  5. Cole o seguinte código no seu arquivo greetings.go e salve o arquivo. 
    package greetings

import "fmt"

// Hello returns a greeting for the named person.
func Hello(name string) string {
    // Return a greeting that embeds the name in a message.
    message := fmt.Sprintf("Hi, %v. Welcome!", name)
    return message
}

    Este é o primeiro código para seu module. Ele retorna uma saudação para qualquer caller que peça uma. Você escreverá código que chama esta função no próximo passo.

    Neste código, você:

    • Declara um package greetings para coletar funções relacionadas.
    • Implementa uma função Hello para retornar a saudação.

      Esta função recebe um parâmetro name cujo tipo é string. A função também retorna uma string. Em Go, uma função cujo nome começa com letra maiúscula pode ser chamada por uma função que não está no mesmo package. Isso é conhecido em Go como um exported name. Para mais sobre exported names, veja Exported names no Go tour.

    • Declara uma variável message para armazenar sua saudação.

      Em Go, o operador := é um atalho para declarar e inicializar uma variável em uma linha (Go usa o valor à direita para determinar o tipo da variável). Fazendo do jeito mais longo, você poderia ter escrito isso como: 

      var message string
message = fmt.Sprintf("Hi, %v. Welcome!", name)
    • Use a função Sprintf do package fmt para criar uma mensagem de saudação. O primeiro argumento é uma string de formato, e Sprintf substitui o valor do parâmetro name pelo verbo de formato %v. Inserir o valor do parâmetro name completa o texto da saudação.
    • Retorne o texto de saudação formatado para o caller.
