Nas últimas alterações que você fará no código do seu módulo, você adicionará suporte para obter saudações para várias pessoas em uma única requisição. Em outras palavras, você tratará uma entrada de múltiplos valores, então emparelhará valores nessa entrada com uma saída de múltiplos valores. Para fazer isso, você precisará passar um conjunto de nomes para uma função que pode retornar uma saudação para cada um deles.

Nota: Este tópico é parte de um tutorial em várias partes que começa com Criar um módulo Go.

Mas há um problema. Mudar o parâmetro da função Hello de um único nome para um conjunto de nomes mudaria a assinatura da função. Se você já tivesse publicado o módulo example.com/greetings e os usuários já tivessem escrito código chamando Hello, essa mudança quebraria seus programas.

Nesta situação, uma escolha melhor é escrever uma nova função com um nome diferente. A nova função receberá múltiplos parâmetros. Isso preserva a função antiga para compatibilidade retroativa.

  1. Em greetings/greetings.go, mude seu código para que fique assim. 
    package greetings

import (
    "errors"
    "fmt"
    "math/rand"
)

// Hello returns a greeting for the named person.
func Hello(name string) (string, error) {
    // If no name was given, return an error with a message.
    if name == "" {
        return name, errors.New("empty name")
    }
    // Create a message using a random format.
    message := fmt.Sprintf(randomFormat(), name)
    return message, nil
}

// Hellos returns a map that associates each of the named people
// with a greeting message.
func Hellos(names []string) (map[string]string, error) {
    // A map to associate names with messages.
    messages := make(map[string]string)
    // Loop through the received slice of names, calling
    // the Hello function to get a message for each name.
    for _, name := range names {
        message, err := Hello(name)
        if err != nil {
            return nil, err
        }
        // In the map, associate the retrieved message with
        // the name.
        messages[name] = message
    }
    return messages, nil
}

// randomFormat returns one of a set of greeting messages. The returned
// message is selected at random.
func randomFormat() string {
    // A slice of message formats.
    formats := []string{
        "Hi, %v. Welcome!",
        "Great to see you, %v!",
        "Hail, %v! Well met!",
    }

    // Return one of the message formats selected at random.
    return formats[rand.Intn(len(formats))]
}

    Neste código, você:

    • Adiciona uma função Hellos cujo parâmetro é um slice de nomes em vez de um único nome. Além disso, você altera um de seus tipos de retorno de string para map para poder retornar nomes mapeados para mensagens de saudação.
    • Faz a nova função Hellos chamar a função Hello existente. Isso ajuda a reduzir duplicação enquanto também deixa ambas as funções no lugar.
    • Cria um map messages para associar cada um dos nomes recebidos (como uma chave) com uma mensagem gerada (como um valor). Em Go, você inicializa um map com a seguinte sintaxe: make(map[key-type]value-type). Você faz a função Hellos retornar este map para o chamador. Para mais sobre maps, veja Go maps em ação no blog do Go.
    • Itera através dos nomes que sua função recebeu, verificando que cada um tem um valor não vazio, então associa uma mensagem com cada um. Neste loop for, range retorna dois valores: o índice do item atual no loop e uma cópia do valor do item. Você não precisa do índice, então você usa o blank identifier do Go (um underscore) para ignorá-lo. Para mais, veja O blank identifier em Effective Go.
  2. No seu código de chamada hello/hello.go, passe um slice de nomes, então imprima o conteúdo do map nomes/mensagens que você recebe de volta.

    Em hello.go, mude seu código para que fique assim. 

    package main

import (
    "fmt"
    "log"

    "example.com/greetings"
)

func main() {
    // Set properties of the predefined Logger, including
    // the log entry prefix and a flag to disable printing
    // the time, source file, and line number.
    log.SetPrefix("greetings: ")
    log.SetFlags(0)

    // A slice of names.
    names := []string{"Gladys", "Samantha", "Darrin"}

    // Request greeting messages for the names.
    messages, err := greetings.Hellos(names)
    if err != nil {
        log.Fatal(err)
    }
    // If no error was returned, print the returned map of
    // messages to the console.
    fmt.Println(messages)
}

    Com essas mudanças, você:

    • Cria uma variável names como um tipo slice contendo três nomes.
    • Passa a variável names como o argumento para a função Hellos.
  3. Na linha de comando, mude para o diretório que contém hello/hello.go, então use go run para confirmar que o código funciona.

    A saída deve ser uma representação string do map associando nomes com mensagens, algo como o seguinte: 

    $ go run .
map[Darrin:Hail, Darrin! Well met! Gladys:Hi, Gladys. Welcome! Samantha:Hail, Samantha! Well met!]

Este tópico introduziu maps para representar pares nome/valor. Ele também introduziu a ideia de preservar compatibilidade retroativa implementando uma nova função para funcionalidade nova ou alterada em um módulo. Para mais sobre compatibilidade retroativa, veja Mantendo seus módulos compatíveis.
