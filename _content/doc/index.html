A linguagem de programação Go é um projeto open source para tornar programadores mais produtivos.

Go é expressiva, concisa, limpa e eficiente. Seus mecanismos de concorrência tornam fácil escrever programas que tiram o máximo proveito de máquinas multicore e em rede, enquanto seu novo sistema de tipos permite construção de programas flexível e modular. Go compila rapidamente para código de máquina, mas tem a conveniência de garbage collection e o poder de reflection em tempo de execução. É uma linguagem rápida, estaticamente tipada e compilada que parece uma linguagem dinamicamente tipada e interpretada.

Acessando bancos de dados relacionais

Uma visão geral dos recursos de acesso a dados do Go.

Abrindo um handle de banco de dados

Você usa o handle de banco de dados do Go para executar operações de banco de dados. Uma vez que você abre um handle com propriedades de conexão de banco de dados, o handle representa um pool de conexão que ele gerencia em seu nome.

Executando instruções SQL que não retornam dados

Para operações SQL que podem mudar o banco de dados, incluindo SQL INSERT, UPDATE e DELETE, você usa métodos Exec.

Consultando dados

Para instruções SELECT que retornam dados de uma consulta, usando o método Query ou QueryRow.

Usando prepared statements

Definir um prepared statement para uso repetido pode ajudar seu código a executar um pouco mais rápido, evitando o overhead de recriar o statement cada vez que seu código executa a operação de banco de dados.

Executando transações

sql.Tx exporta métodos representando semânticas específicas de transação, incluindo Commit e Rollback, bem como métodos que você usa para executar operações comuns de banco de dados.

Cancelando operações de banco de dados em andamento

Usando context.Context, você pode fazer com que as chamadas de função e serviços da sua aplicação parem de funcionar cedo e retornem um erro quando seu processamento não for mais necessário.

Gerenciando conexões

Para alguns programas avançados, você pode precisar ajustar parâmetros do pool de conexões ou trabalhar com conexões explicitamente.

Evitando risco de SQL injection

Você pode evitar um risco de SQL injection fornecendo valores de parâmetro SQL como argumentos de função do package sql

Desenvolvendo uma atualização de versão major

Uma atualização de versão major pode ser muito disruptiva para os usuários do seu módulo porque inclui mudanças incompatíveis e representa um novo módulo. Aprenda mais neste tópico.

Publicando um módulo

Quando você quer tornar um módulo disponível para outros desenvolvedores, você o publica para que seja visível para ferramentas Go. Uma vez que você publicou o módulo, desenvolvedores importando seus packages serão capazes de resolver uma dependência no módulo executando comandos como go get.

Numeração de versão de módulo

O desenvolvedor de um módulo usa cada parte do número de versão de um módulo para sinalizar a estabilidade e compatibilidade reversa da versão. Para cada novo release, o número de versão de release de um módulo reflete especificamente a natureza das mudanças do módulo desde o release anterior.

Um Tour em Vídeo de Go

Três coisas que tornam Go rápida, divertida e produtiva: interfaces, reflection e concorrência. Constrói um web crawler de brinquedo para demonstrar isso.

Código que cresce com graça

Um dos principais objetivos de design do Go é adaptabilidade de código; que deve ser fácil pegar um design simples e construir sobre ele de forma limpa e natural. Nesta palestra Andrew Gerrand descreve um servidor simples de "chat roulette" que combina pares de conexões TCP entrantes, e então usa os mecanismos de concorrência do Go, interfaces e biblioteca padrão para estendê-lo com uma interface web e outros recursos. Enquanto a função do programa muda dramaticamente, a flexibilidade do Go preserva o design original à medida que ele cresce.

Padrões de Concorrência em Go

Concorrência é a chave para projetar serviços de rede de alto desempenho. As primitivas de concorrência do Go (goroutines e channels) fornecem um meio simples e eficiente de expressar execução concorrente. Nesta palestra vemos como problemas de concorrência complicados podem ser resolvidos graciosamente com código Go simples.
