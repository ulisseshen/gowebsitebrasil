Instalação do Go

Selecione a aba para o sistema operacional do seu computador abaixo e siga suas instruções de instalação.

  1. Remova qualquer instalação anterior do Go excluindo a pasta /usr/local/go (se ela existir), e então extraia o arquivo que você acabou de baixar em /usr/local, criando uma nova árvore Go em /usr/local/go: 
          $ rm -rf /usr/local/go && tar -C /usr/local -xzf go1.14.3.linux-amd64.tar.gz

    (Você pode precisar executar cada comando separadamente com as permissões necessárias, como root ou através de sudo.)

    Não descompacte o arquivo em uma árvore /usr/local/go existente. Isso é conhecido por produzir instalações Go quebradas.

  2. Adicione /usr/local/go/bin à variável de ambiente PATH.

    Você pode fazer isso adicionando a seguinte linha ao seu $HOME/.profile ou /etc/profile (para uma instalação em todo o sistema): 

              export PATH=$PATH:/usr/local/go/bin

    Nota: Alterações feitas em um arquivo de perfil podem não ser aplicadas até a próxima vez que você fizer login no seu computador. Para aplicar as alterações imediatamente, execute os comandos shell diretamente ou execute-os do perfil usando um comando como source $HOME/.profile.

  3. Verifique se você instalou o Go abrindo um prompt de comando e digitando o seguinte comando: 
              $ go version
  4. Confirme que o comando imprime a versão instalada do Go.
  1. Abra o arquivo de pacote que você baixou e siga as instruções para instalar Go.

    O pacote instala a distribuição Go em /usr/local/go. O pacote deve colocar o diretório /usr/local/go/bin em sua variável de ambiente PATH. Você pode precisar reiniciar quaisquer sessões de Terminal abertas para que a alteração tenha efeito.

  2. Verifique se você instalou o Go abrindo um prompt de comando e digitando o seguinte comando: 
              $ go version
  3. Confirme que o comando imprime a versão instalada do Go.
  1. Abra o arquivo MSI que você baixou e siga as instruções para instalar Go.

    Por padrão, o instalador instalará Go em Program Files ou Program Files (x86). Você pode alterar o local conforme necessário. Após a instalação, você precisará fechar e reabrir quaisquer prompts de comando abertos para que as alterações no ambiente feitas pelo instalador sejam refletidas no prompt de comando.

  2. Verifique se você instalou o Go.
    1. No Windows, clique no menu Start.
    2. Na caixa de pesquisa do menu, digite cmd e pressione a tecla Enter.
    3. Na janela de Prompt de Comando que aparecer, digite o seguinte comando: 
                    $ go version
    4. Confirme que o comando imprime a versão instalada do Go.
