Esta página resume as mudanças entre releases estáveis oficiais do Go. O change log tem os detalhes completos.

Para atualizar para um release específico, use:

git fetch --tags
git checkout goX.Y.Z

Política de Release

Cada release major do Go é suportado até que existam dois releases major mais novos. Por exemplo, Go 1.5 foi suportado até o release Go 1.7, e Go 1.6 foi suportado até o release Go 1.8. Corrigimos problemas críticos, incluindo problemas críticos de segurança, em releases suportados conforme necessário emitindo revisões minor (por exemplo, Go 1.6.1, Go 1.6.2, e assim por diante).

go1.8 (lançado em 2017-02-16)

Go 1.8 é um release major do Go. Leia as Notas de Release do Go 1.8 para mais informações.

Revisões minor

go1.8.1 (lançado em 2017-04-07) inclui correções para o compilador, linker, runtime, documentação, comando go e os packages crypto/tls, encoding/xml, image/png, net, net/http, reflect, text/template, e time. Veja o milestone Go 1.8.1 em nosso issue tracker para detalhes.

go1.8.2 (lançado em 2017-05-23) inclui uma correção de segurança para o package crypto/elliptic. Veja o milestone Go 1.8.2 em nosso issue tracker para detalhes.

go1.8.3 (lançado em 2017-05-24) inclui correções para o compilador, runtime, documentação, e o package database/sql. Veja o milestone Go 1.8.3 em nosso issue tracker para detalhes.

go1.8.4 (lançado em 2017-10-04) inclui duas correções de segurança. Contém as mesmas correções que Go 1.9.1 e foi lançado ao mesmo tempo. Veja o milestone Go 1.8.4 em nosso issue tracker para detalhes.

go1.8.5 (lançado em 2017-10-25) inclui correções para o compilador, linker, runtime, documentação, comando go, e os packages crypto/x509 e net/smtp. Inclui uma correção para um bug introduzido no Go 1.8.4 que quebrou go get de repositórios não-Git sob certas condições. Veja o milestone Go 1.8.5 em nosso issue tracker para detalhes.

go1.8.6 (lançado em 2018-01-22) inclui a mesma correção em math/big que Go 1.9.3 e foi lançado ao mesmo tempo. Veja o milestone Go 1.8.6 em nosso issue tracker para detalhes.

go1.8.7 (lançado em 2018-02-07) inclui uma correção de segurança para "go get". Contém a mesma correção que Go 1.9.4 e foi lançado ao mesmo tempo. Veja o milestone Go 1.8.7 em nosso issue tracker para detalhes.

go1 (lançado em 2012-03-28)

Go 1 é um release major do Go que será estável no longo prazo. Leia as Notas de Release do Go 1 para mais informações.

A intenção é que programas escritos para Go 1 continuem a compilar e executar corretamente, inalterados, sob versões futuras do Go 1. Leia o documento de compatibilidade do Go 1 para mais sobre o futuro do Go 1.

O release go1 corresponde a weekly.2012-03-27.

Revisões minor

go1.0.1 (lançado em 2012-04-25) foi emitido para corrigir um bug de escape analysis que pode levar a corrupção de memória. Também inclui várias correções menores de código e documentação.

go1.0.2 (lançado em 2012-06-13) foi emitido para corrigir dois bugs na implementação de maps usando chaves struct ou array: issue 3695 e issue 3573. Também inclui muitas correções menores de código e documentação.

go1.0.3 (lançado em 2012-09-21) inclui correções menores de código e documentação.
