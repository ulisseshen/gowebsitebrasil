Existe um conjunto de programas para construir e processar código-fonte Go. Em vez de serem executados diretamente, os programas do conjunto geralmente são invocados pelo programa go.

A maneira mais comum de executar esses programas é como um subcomando do programa go, por exemplo, como go fmt. Executado dessa forma, o comando opera em pacotes completos de código-fonte Go, com o programa go invocando o binário subjacente com argumentos apropriados para processamento em nível de pacote.

Os programas também podem ser executados como binários standalone, com argumentos não modificados, usando o subcomando tool do go, como go tool cgo. Para a maioria dos comandos, isso é útil principalmente para debugging. Alguns dos comandos, como pprof, são acessíveis apenas através do subcomando tool do go.

O processo de instalação do Go também instala um executável chamado gofmt, equivalente a go fmt, porque é referenciado com frequência.

Clique nos links para mais documentação, métodos de invocação e detalhes de uso.

Nome      Sinopse
go      O programa go gerencia código-fonte Go e executa os outros comandos listados aqui. Veja a documentação de comandos para detalhes de uso.
cgo      Cgo permite a criação de pacotes Go que chamam código C.
cover      Cover é um programa para criar e analisar os perfis de cobertura gerados por "go test -coverprofile".
fix      Fix encontra programas Go que usam recursos antigos da linguagem e bibliotecas e os reescreve para usar recursos mais novos.
fmt      Fmt formata pacotes Go, também está disponível como um comando gofmt independente com opções mais gerais.
doc      Doc extrai e gera documentação para pacotes Go.
vet      Vet examina código-fonte Go e relata construções suspeitas, como chamadas Printf cujos argumentos não se alinham com a string de formato.
