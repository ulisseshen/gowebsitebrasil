Introdução

Este documento lista plugins de editor e IDEs comumente usados do ecossistema Go que tornam o desenvolvimento em Go mais produtivo e fluido. Uma lista abrangente de suporte de editores e IDEs para desenvolvimento Go está disponível em the wiki.

Opções

O ecossistema Go fornece uma variedade de plugins de editor e IDEs para aprimorar sua experiência diária de edição, navegação, teste e debugging.

  • Visual Studio Code: A extensão Go fornece suporte para a linguagem de programação Go
  • GoLand: GoLand é distribuído como uma IDE standalone ou como um plugin para IntelliJ IDEA Ultimate
  • vim: o plugin vim-go fornece suporte à linguagem de programação Go

Observe que estas são apenas algumas das principais soluções; uma lista mais abrangente mantida pela comunidade de IDEs e plugins de editor de texto está disponível no Wiki.
